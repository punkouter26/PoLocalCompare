Models, Inference Proxies, Pricing & the Auto-Judge

Snapshot of src/PoLocalCompare.Api/Features/Models/ModelSeeder.cs, appsettings.json and the inference layer (Common/Inference/*, Features/Duels/FoundryDuelJudge.cs). Generated 2026-08-21 from current master. Three tiers, in order: Executive → Architectural → Implementation.

TIER 1Executive summary (30 s)

PoLocalCompare routes duels through three inference paths: Remote (Azure AI Foundry chat completion + SSE), LocalService (Ollama, Development only), and Local (WebLLM/WebGPU inside the browser tab). The catalog currently lists 21 seeded models — 7 browser, 2 Ollama, 12 remote. When no human picks a winner within AiJudge:DelaySeconds the auto-judge calls Foundry (default gpt-5.4-nano) and records the verdict with VerdictSource = Ai so the leaderboard can be filtered.

Remote: 12 models LocalService: 2 models (Development only) Local (browser): 7 models Auto-judge: Foundry chat Pricing: $/M tokens, sourced from ModelSeeder

Architectural view

TIER 2How inference flows through the system

Inference is invoked from exactly one place — DuelExecutionService — and the path it takes depends on the ModelType of each side of the duel. Browser models are an exception: their inference runs in the browser web-worker and the result is POSTed to POST /api/duels/{id}/local-result; the server never sees that inference at all.

Trigger & fallback rules

  • Two-endpoint Foundry fallback: FoundryChatRequest.DeploymentUrl is tried first; on 404 the proxy falls back to ModelInferenceUrl with includeModelField: true.
  • Reasoning-model body shape: FoundryChatRequest.IsReasoningModel detects gpt-5*, o1/o3/o4 and emits max_completion_tokens (omitting temperature). Classic models get max_tokens and temperature.
  • Stream-options allow-list: FoundryChatRequest.SupportsStreamUsage is deny-by-default — Codestral 2501 (Mistral MaaS) returns HTTP 422 if stream_options is sent.
  • Browser model weights: optional but vendored under wwwroot/models/ (and _libs/ for model_lib); otherwise WebLLM falls back to CDN.
  • Auto-judge stand-down: re-reads the duel after the grace window; bails out on anything but Pending; one-sided failures award a walkover; both-side failures leave the duel Pending.
  • Rate-limit re-queue: HTTP 429 with a Retry-After header is re-queued up to RateLimitRetryMax times so a Foundry burst does not silently turn the demo into one-decision.

Cost calculation (where the number on screen comes from)

// features/Duels/DuelResultEnricher.cs — server side
ApiCostUsd =
    ((inputTokens  / 1_000_000m) * model.InputTokenPricePerMillion) +
    ((outputTokens / 1_000_000m) * model.OutputTokenPricePerMillion);

// Local / LocalService (no per-token rate)
// features/Duels/GreenStatsCalculator.cs
EnergyWh = (TdpWatts × TotalDurationMs) / 3_600_000
EnergyCostUsd = EnergyWh × GreenStats:ElectricityRateUsd    // default 0.12
